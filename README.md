# 🍔🍕 Burgerizzaa — Pizza & Burger Website

Burgerizzaa is a modern and responsive web application for a pizza and burger restaurant.  
It allows users to explore menu items, view delicious food options, and enjoy a sleek and interactive UI.

---

## 🚀 Features
- Browse tasty pizza and burger items with images and details.
- Simple and user‑friendly interface.
- Fully responsive layout for mobile and desktop.
- Built with modern web tooling: React + TypeScript + Vite.

---

## 🛠 Tech Stack
- **Vite** – Fast frontend build tool.
- **React** – UI library for building components.
- **TypeScript** – Adds type safety to JavaScript.
- **ESLint** – Linting and code standards.
